# FUTO Voice Input 1.5.2

## Keyboard dictation

- Dictation goes on after you move the cursor or edit the text field while
  recording. The live text shown so far is kept as it is, and new speech is
  inserted at the new cursor position. Before, dictation stopped in the field
  after such a change.
- This works with models that support the editing buttons. With other models,
  moving the cursor still ends the dictation, as before.
