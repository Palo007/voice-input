# FUTO Voice Input 1.5.0

New models, routing between Slovak and English, a set of editing tools on the
keyboard dictation screen, and an easier model picker. ASR4ALL Medium stays the
default model and saved model choices are kept.

## Models and recognition

- Parakeet Ultra can be selected as a model. It stays loaded between recordings.
- A Slovak fine-tune of Parakeet TDT V3 can be selected as a model.
- SK | EN routing picks the Slovak model or your selected model based on the
  dictation language. All speech is kept if the language changes partway through
  a recording, and quiet input is boosted.
- Live text at pauses, plus an option to keep two Parakeet models loaded.
- Whole-recording retranscribe: after recording, the full recording can be
  transcribed again.
- Model Options lists downloaded models first in each model family.

## Keyboard dictation screen

- Editing buttons while dictating: delete a character or word, question mark and
  space.
- A lowercase (Aa→a) button and a reorganized editing bar. Names with
  apostrophes and hyphens stay together.
- Voice commands and formatting that adapts to the input field.

## History and appearance

- Saved recordings can be played back in history.
- Custom theme colors.

## Documentation

- A recognition troubleshooting guide and an on-phone replay bench.
